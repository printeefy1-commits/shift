SHIFT — FULL LOCAL EDITION

1. Extract the ZIP into a folder.
2. Double-click index.html. Use current Chrome, Edge, Firefox or Safari.
3. Click Admin sign in to edit immediately; no password is requested for now.
4. To restore the password prompt, click Enable password protection after signing
   in. An existing password is retained; otherwise choose at least 12 characters.

No Python, installation, internet connection or local server is required.

Your data is stored only in this browser's local storage. Keep the HTML file
at the same location and use the same browser/profile. Browser handling of
file storage varies; clearing browsing data, private mode, moving the file
or switching browsers can lose access to your saved data. Export JSON backups
regularly and before moving/updating the application. Restore a backup after
signing in as administrator in the new browser. Imports replace local
schedules; they preserve the local password and protection setting. Passwords are not in backups.
If you forget the local password, use a backed-up JSON file in a fresh browser
profile / fresh local copy and create a new local administrator before restoring.

Share read-only copy downloads a self-contained HTML snapshot for the team.
It contains no administrator password and offers no edit controls. Recipients
need no installation. It does not synchronize: export and send a new copy after
changes. The local password and read-only controls are convenience features;
people with access to browser developer tools or the file can bypass local UI
restrictions. There is no secure remote account or multi-device live sync.

The 35-month history, both November 2026 sources and difference table are
included. Generation follows regular-month rules, with Friday/holiday rotation
from 2025-01-01 and Sid Ali / Lamine excluded by default. Ramadan planning is
not implemented. Add confirmed future religious holiday dates in Public holidays.
Admin schedule: compact full-month view; click a cell to select engineer/state.
Click a time heading to edit it. Comfortable view enlarges the cells.
Switch engineers offers pair-only changes or replanning remaining turns.
Recovery is two days after each actual evening block.
Phone numbers and full names are editable in Team members.
Choose Plan weekly rotation, review the starting roles and select each Friday.
After D, daytime lasts 0 weeks with 4 available rotating engineers,
1 with 5, 2 with 6, or 3 with 7. Four engineers follow A/B/C/D directly.
The shared E/F/G column shows all engineers in that stage together.
With 6 rotating engineers, each stays visibly in F for 2 weeks.
Friday/Saturday show only working engineers; inactive cells are blank/white.
Then Saturday daytime prepares the Sunday-Tuesday evening block.
Friday recovery is the following Sunday. Yougo is eligible for Friday; when
he works Friday, B's candidate keeps the next Wednesday-Saturday night turn.
Drag engineers on the same date to choose a one-shift swap or a cycle change.
The cycle option follows rules 5/8 from that date; earlier dates stay unchanged.
Use Absences / return dates for Formation, Conge or Maladie date ranges.
The absent engineer keeps day/evening eligibility and automatically returns
after the last absent date. The cycle uses the available team count each day.
Use Plan from date to create a replacement draft; saved months stay unchanged
until publication. Next month continues the previous month's turns and queue.
Daytime-only engineers keep the final columns. Holidays use the shared turn,
with an optional administrator override. Cancel/discard keeps published data.
Review it and publish/save. Leave/training/illness apply only to that date.
Export a backup before updating. Replace index.html at the SAME location and
use the SAME browser/profile to retain existing schedules and data. The storage
key is unchanged. Existing password hashes are kept while the prompt is off.
